I publish code and models when they can be useful outside one organisation. Open repositories also make it easier to inspect assumptions and improve them in public.

## Selected projects

### [DataGovOps](https://github.com/frecke/datagovops)

Open reference models and standards profiles for machine-readable data governance, with a particular interest in Swedish public-sector interoperability. The repository includes schemas, fictional examples, and validation tooling. **Status:** early-stage research and reference implementation.

### [DataGovSecOps](https://github.com/frecke/datagovsecops)

A security and assurance extension to DataGovOps, exploring classification, access, provenance, control ownership, and evidence for governed data products. **Status:** early-stage research and reference implementation; the example controls are not an accreditation.

### [hostsctl](https://github.com/frecke/hostsctl)

A small zsh tool for managing tagged entries in the macOS hosts file. It is a focused example of the kind of utility I enjoy building: narrow scope, explicit changes, and a path to testing. See its repository for installation and current limitations.

The full public activity is on [GitHub](https://github.com/frecke). A fork or experiment in that list should not be read as a maintained project; the repository itself is the source for its scope, license, and status.
